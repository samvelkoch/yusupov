# Правила для этого репозитория

- Сайт-спутник к «Мемуарам» Феликса Юсупова для Ивана Шешокина (книгу он уже прочитал). Его дневник «Бранч с князем Юсуповым» публикуется целиком, без правки и пересказа.
- Данные: `data.json` собирается `python3 src/build.py` из пофайловых глав `src/data/chNN.json`, людей `src/data/people.py` и дневника `src/diary.json`. Картинки: `img.q` (поиск), `img.wiki` ("ru:Статья" — главная картинка статьи) или `img.file`. При ручной правке сохраняйте поля `img.src/full/file`, их пишет `tools/fetch_images.py` (GitHub Actions).
- Нумерация глав сквозная 1–46 (книга I: 1–27, книга II: 28–46); на экране — «I·N» / «II·N».
- У каждого элемента (цитата, дата, пункт мира, событие человека, запись дневника) обязательно поле `ch`: на нём работает режим «я прочитал до главы».
- Цитаты только дословно по изданию. Факты и трактовки разделены (`kind: fact | reading`). Ошибки Феликса в датах и фактах отмечаются явно.
- Дизайн: тот же, что у samvelkoch/eastofeden — монохром плюс темы «Сепия» и «Ночная сепия». Телефон — основной сценарий. Тексты по-русски, коротко.
- localStorage-префикс `yus-`.
