# Бранч с князем

Сайт-спутник к «Мемуарам» князя Феликса Юсупова и читательскому дневнику Ивана Шешокина «Бранч с князем Юсуповым».

https://samvelkoch.github.io/yusupov/

Главы, контекст, 243 цитаты, 104 человека, родословная, хронология, мир эпохи и весь дневник Ивана. Как сделано — [method.html](method.html).
